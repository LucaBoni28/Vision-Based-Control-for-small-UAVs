# Graphs Generation and Data Logging

This folder contains the Python scripts required to generate the datasets and performance plots for the thesis evaluation (Chapters 4, 5, and 6).

## Directory Structure
- `scripts/`: Contains all the python loggers and plotting scripts.
- `logs/`: Automatically generated folder where the raw `.csv` datasets are saved.
- `plots/`: Automatically generated folder where `plotter.py` saves the output `.png` graphs.

## How to Collect Data

You can organize your tests into separate subfolders by appending `--run-name <folder_name>` to any of the logging scripts. If you omit it, files are saved directly in the root of `logs/`.

### 1. Hardware Performance Benchmarking (Chapter 4)
This script runs strictly on the **NVIDIA Jetson Orin NX**. It uses the `jtop` library to measure CPU, GPU, DLA, RAM, and Power draw.
```bash
python scripts/hardware_logger.py bytetrack --run-name run_001
```
*(Repeat for `deepsort` and `botsort` by replacing the algorithm name).*

### 2. Full Pipeline Tracking & Latency Benchmarks (Chapter 6)
To evaluate the end-to-end latency, FPS, and tracking consistency (ID switches, jitter, distances), use the main `tracking.py` script located in the root of the repository. It imports `thesis_logger.py` automatically when you pass the `--test combined` flag.
```bash
# Run this from the root repository directory, NOT inside graphs_generation/
python tracking.py --test combined --tracker bytetrack --run-name run_001
```
*(Repeat for other trackers to collect comparative data).*

## How to Generate the Graphs

Once you have collected the `.csv` logs, run the `plotter.py` script. It will automatically detect the CSV files in your `logs/` directory and generate thesis-ready, formatted `.png` images in the `plots/` directory.

```bash
# To plot the default logs folder:
python scripts/plotter.py

# To plot logs from a specific test run:
python scripts/plotter.py --run-name run_001
```

### Outputs generated by `plotter.py`:
- `hardware_comparison_stats.png`: CPU, GPU, RAM, Power comparison across trackers.
- `benchmark_avg_fps_latency.png` & `benchmark_avg_id_switches_jitter.png`: Bar charts comparing tracker performance.
- `benchmark_timeseries_fps_latency.png` & `benchmark_timeseries_id_switches_jitter.png`: Line plots showing stability over time.
- `telemetry_velocities_distance_<tracker>.png`: The 5-subplot graph showing velocity commands, area, and estimated distance.
- `step_response_yaw.png`: Step response curve showing overshoot, settling time, RMSE, and damping ratio.
